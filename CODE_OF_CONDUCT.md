# Code of Conduct

## The short version

Be useful. Do not be a jerk.

## Scope

Issues, pull requests and discussions in this repository.

## Standards

Expected:

- Assume the person asking has read the code and is stuck, not lazy.
- Critique the approach, not the author.
- If you are wrong, say so and move on.

Not acceptable:

- Personal attacks or demeaning comments about someone's experience.
- Harassment, public or private.
- Publishing anyone's private information.

## Enforcement

The maintainer may edit, remove or reject contributions that violate this, and
may block accounts for repeat behaviour. Report privately via the Security tab.
